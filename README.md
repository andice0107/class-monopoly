# 課室大富翁・Codex 優化版

直接開啟 `index.html` 即可遊玩。主遊戲、330 題內建題庫、文字檔匯入及動畫皆可離線使用；`.docx` 匯入需要網路下載解析器。

## 這次優化

- 馬卡龍滿版棋盤、清楚的隊伍狀態與圈數進度、深綠分數及深橘圈數。
- 左側題目回顧、中央骰子操作、右側結果面板採互不覆蓋的配置。尚未答題時呈現玩法提示，利用中央空間。
- 大字雙欄選項、選取勾號、骰子搖動、逐格行走、翻牌與結果進場動畫；支援系統減少動態效果設定。
- 保留原版設定、計分、題庫發牌制、洗牌答案對應、兩種擲骰模式及結算規則；答對預設為 100 分，扣分可為負數。
- 內建國小低年級綜合題庫 330 題；題庫一輪不重複，全部出過後重洗。
- 可選擇監獄／醫院格。被送入者暫停兩回合、出來扣 150 分；探訪時付給同格每位仍不能行動的角色 50 分。
- 翻盤機制只在最後一名達自訂進度或分數差時啟動。骰子／轉盤永遠為 1～6；六步內機會／命運格只獲小幅機率加成，監獄／醫院、起點和終點機率不受影響。
- 暫停時同時停止移動與倒數；結算會關閉題目視窗，重開局取消舊局待執行動作。這些是對既有暫停與結算功能的修正。

## 檔案

- `index.html`：可獨立使用的遊戲，無須旁邊其他檔案。
- `題目範本.txt`：可編輯並匯入的題目格式範本。

## 驗證範圍

程式語法、330 題題目與答案對應、負分、出院扣費、慰問金、監獄範圍、翻盤門檻與卡牌機率均已自動檢查。六步落點的全部 729 種機率配置，也確認了加成不會改變監獄／醫院、起點或終點的骰率。

未實測教室投影機、實體平板觸控或連網 `.docx` 解析；後排可讀性仍需依實際投影確認。
