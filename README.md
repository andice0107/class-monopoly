# 課室大富翁・Codex 優化版

直接雙擊 `class-monopoly.html`，使用 Chrome 或 Edge 開啟即可。主遊戲、50 題內建題庫、文字檔匯入及動畫皆可離線使用；延續原版的 `.docx` 匯入需要網路下載解析器。

## 這次優化

- 馬卡龍滿版棋盤、清楚的隊伍狀態與圈數進度、深綠分數及深橘圈數。
- 左側題目回顧、中央骰子操作、右側結果面板採互不覆蓋的配置。尚未答題時呈現玩法提示，利用中央空間。
- 大字雙欄選項、選取勾號、骰子搖動、逐格行走、翻牌與結果進場動畫；支援系統減少動態效果設定。
- 保留原版設定、計分、題庫發牌制、洗牌答案對應、兩種擲骰模式、16 張卡牌及結算規則。
- 依需求規格排除原版頭像池中的昆蟲／鼠類，內建隨附的 50 題範例。
- 暫停時同時停止移動與倒數；結算會關閉題目視窗，重開局取消舊局待執行動作。這些是對既有暫停與結算功能的修正。

## 檔案

- `class-monopoly.html`：可獨立使用的遊戲，無須旁邊其他檔案。
- `題目範本.txt`：原附 50 題，可編輯並匯入。
- `需求規格書-原始參考.md`：原需求副本。
- `預覽-*.png`：設定、棋盤、答題、結果與平板畫面。
- `驗證結果.json`：自動化測試紀錄。
- `製作與驗證/`：建置來源與測試程式，日常遊戲不需要使用。

## 驗證範圍

使用本機 Chromium：10～36 格 × 1920×1080、1440×900、1366×768、1024×768、820×1180、768×1024，共 162 組配置。檢查格子與面板重疊、相鄰格至少 4px 間距、棋格及中央內容裁切與橫向溢出。

完成 2,000 次選項洗牌與 4,000 次正誤判分；題庫整輪不重複；16 張卡牌逐張驗證目的地、分數與開題／換人／再擲流程；實際按鈕複選送出、結果保留、起點進退、完成圈數、總時間結算、暫停、逾時送出與離線檔案開啟。JavaScript 已通過 `node --check`。

50 題範例在 1366×768、1024×768、768×1024 的題目視窗皆不需捲動。自訂極長題幹、選項或隊伍名稱仍可能需要捲動／換行；小尺寸螢幕優先保留文字大小，必要時整頁可往下捲動。

未實測教室投影機、實體平板觸控或連網 `.docx` 解析；後排可讀性仍需依實際投影確認。未更動上層原始 HTML 與題庫。
